# External AI Review Request

> 供外部审查模型(如独立 ChatGPT / DeepSeek 会话)读取本仓库后回答。

## 请重点检查

* 逆向分析结论是否严谨 —— 报告 01–14 中是否存在错误假设或过度推断
* 是否把「代码已实现但未测试」误标为「已验证」
* API 地图(08)的端点/方法/认证是否与证据一致
* 数据模型(09)是否有凭空捏造的字段名
* 移动端 Capacitor 判定是否成立(12)
* 原生二进制「无自研代码」结论是否成立(14)
* 交接脚本 `scripts/ai_checkpoint.py` 的 Secret 扫描是否有绕过路径
* 下一阶段优先级是否合理

## 不要做什么

* 不要为了不同而不同, 无证据推翻现有设计
* 不要只根据 README 判断整个项目 —— 请检查实际报告、脚本与变更记录
* 不要猜测未解出的内容 —— 未解出的应标记为 UNKNOWN, 而非推测

## 优先检查的路径

```
reports/            (01–14 全套分析报告)
scripts/            (自写辅助脚本, 含安全扫描)
indexes/            (文件索引)
.ai-handoff/        (交接文档)
```

## 输出建议

按以下格式给出结论:

1. 总体判断(是否有方向性错误)
2. 逐报告问题列表(报告编号 + 具体问题 + 建议)
3. 未验证声称(哪些结论证据不足)
4. 下一轮开发提示词建议
